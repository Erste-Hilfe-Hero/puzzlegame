# Amy's Tasty World

Merge-2 puzzle game (working title). Amy travels the world, merges ingredients into dishes and drinks, serves guests and restores cafes in Paris, Tokyo and New York.
Monetization: in-app purchases only, no ads, no purchase pop-ups (shop only when the player opens it).

- `web/` - playable HTML5 prototype (open `web/index.html`). Purchases are test purchases.
- `docs/konzept.md` - concept, shop plan, milestones (German).

Run locally: `npx serve web` or any static file server.
